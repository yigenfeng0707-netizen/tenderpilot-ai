# 评委 60 秒路径

口播与点击一一对应；只演示真实已上线能力。

## 口播（约 60s）

1. **问题（10s）**：申报/投标通知又长又杂，团队容易漏截止、漏证据、先写承诺再补材料。
2. **方案（10s）**：TenderPilot 把脱敏文本变成要求清单、证据矩阵、风险任务和受约束草稿——证据优先，不是聊天框。
3. **现场（30s）**：打开 Demo → 看页眉「规则拆解（零 Key）」→ 加载脱敏样例 → 拆解要求 → 指认原文引用、矩阵状态、任务与草稿依据。
4. **边界（10s）**：可选手动增强拆解；失败会回退规则。草稿需人工审核；页脚可留真实反馈。

| 步 | 动作 | 期望 |
| --- | --- | --- |
| 1 | 打开 https://gsym236998-tenderpilot-ai.ms.show/ | HTTP 可达；页眉有模式徽章 |

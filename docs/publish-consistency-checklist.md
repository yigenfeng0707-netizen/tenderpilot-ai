## 最终提交前

1. 在未登录浏览器中打开 Demo 与研习社文章链接。
2. 将最终“作品名称、作品简介、Demo URL、文章 URL、额外激励选择”汇总为预览。
3. 用户明确批准“提交作品”后，才点击赛事门户的“提交作品”。
4. 提交后刷新门户，确认内容持久化。
